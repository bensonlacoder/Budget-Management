# 07: What-if mode

**Requirements:** FR-36

**What to build:** The user can try a different balance, reserve, end date, or set of habits and see the advice that would result, without changing their saved data or the balance their friends see.

**Blocked by:** 06 (Dining habits and habit-aware suggestions)

**Status:** ready-for-agent

- [ ] A clearly labelled what-if mode can be turned on and off
- [ ] Values changed in what-if mode update the advice shown there only
- [ ] The saved balance, purchase history, and balance friends see stay unchanged while it is on and after it is turned off
- [ ] Turning it off brings back the advice for the saved values
- [ ] Tests confirm nothing is saved while what-if mode is on
